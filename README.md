# Claude Code skills

Small, self-contained skills for Claude Code. Each folder is one skill with a `SKILL.md`.

| Skill | What it does |
| --- | --- |
| `improve-idea` | Turns a rough idea or annoyance into a grounded entry in a repo's `IMPROVEMENTS.md`. |
| `improve-list` | Shows that backlog as one numbered list, Small and Big. |
| `improve-refinement` | Asks the open questions an entry is holding and rewrites it so it can be built. |
| `like-im-5` | Re-explains the last technical explanation in plain cause and effect. |

## Install

Link a skill into your skills folder:

```sh
ln -s "$(pwd)/improve-idea" ~/.claude/skills/improve-idea
```
